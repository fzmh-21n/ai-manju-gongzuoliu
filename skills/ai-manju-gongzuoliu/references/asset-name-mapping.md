# 角色图与场景图资产名称映射

## 适用范围与来源

同时适用于15秒与30秒视频提示词。资产库为用户工作目录下的“最终资产”，清单为 `最终资产/资产清单.json`。两套视频都使用同一资产库，按本节实际剧情状态选图。

## 清单与精确名称

每张已生成图片至少记录：资产名称、资产类型、对应人物/地点、状态版本、生成顺序、实际文件名、完整路径及必要说明。角色状态仅在明显外形变化时新增，普通情绪、姿态、站位或轻微污点由分镜描述处理。

【出场人物】【出场场景】引用的命名以清单的“实际文件名”为准，逐字符复制，包括前缀、三位序号、状态及扩展名；可在其后加括号说明本节身份或使用位置。清单的简称、别名不替代实际文件名。

人物示例：

`角色图_002_王姨换装版.png（已换成原文指定的新衣服）`

场景示例：

`场景图_001_整洁的王姨客厅四视角.png（当前会客区域）`

多个人物或多个背景分别列出，不合成模糊描述。不擅自缩写、改名、同义替换，不编造群体成员的身份。主提示词内的人物和场景引用同样使用清单中的精确实际文件名，不能在模块列文件名、主提示词改成别名。

## 现场人物与声音来源

1. 【出场人物】按实际在场者判断，沉默者、旁听者及侧后方人物都保留。
2. 上一节在场且未离开的人继续在场；同桌或同屋人物不因镜头聚焦他人而消失。
3. 明确转场后按新场景重新核定，不把全剧人物机械塞进每节。
4. 人物模块、主提示词人物清单及实际画面人物一致；未说话者持续倾听、目光跟随、即时反应。
5. 左右位置、坐站姿态、朝向、距离、接触状态、手持道具和动作惯性跨节继承，改变时须有真实过渡动作。
6. 电话、历史录音、群消息只作为相应声音/信息来源，不生成同空间分身。电话两端需要入镜时分别明确独立空间及已有资产。
7. 纯旁白不虚构现场人物；OS标明所属角色并闭嘴。别人不能因听到内心OS而接话。历史录音或无实体旁白与尾镜看见发声者的要求冲突时，先在原文范围内调整自然分节；仍无法兼容则报告具体冲突并询问处理，不自行豁免尾镜要求，也不捏造旁白实体或资产。

## 每节资产核对与缺项处理

1. 读取本节实际在场者、实际入镜背景、人物外形和场景环境状态。
2. 查清单，核对图片文件确实存在、对应状态正确。
3. 逐项复制实际文件名，必要描述放在括号内；在两个模块和主提示词交叉检查。
4. 找不到时列明缺失人物/场景及状态，停止受影响条目及其后续连续提示词；不编造文件名、不近似替代。
5. 返回角色图或场景图步骤，完成16:9图片、保存到“最终资产”、登记实际文件名后，从中断处继续。

## 自检

- 名称是否逐字符匹配清单及磁盘文件，状态是否与本节一致。
- 是否包含全部现场人物，且与主提示词和画面一致。
- 场景是否指向准确图片，而不是只有空间描述。
- 沉默者是否持续在场，空间、姿态、道具和动作因果是否连续。
- 声音源是否正确，电话是否独立空间，OS是否闭嘴且不被他人听见。
- 是否已先补齐缺失资产再续写，未用伪造名称或未出图状态。
