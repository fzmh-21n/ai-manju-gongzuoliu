# 角色图与场景图最终资产名称映射规则

## 优先级与目的

本规则是共同工作流的第二优先级硬规则，仅次于“两套导演提示词绝对隔离”。它只负责让正式分镜中的人物和背景唯一对应到实际图片，不覆盖所选导演提示词的栏目责任、时长、镜数、标题或声音规则。

## 最终资产名的唯一标准

1. 最终资产名是实际交付图片的文件名主干：保留既有三位编号、人物或场景名、状态后缀；删除 `.png`、`.jpg`、`.jpeg`、`.webp` 等扩展名。
2. 例：文件 `015_小满绑架受冻版.png` 在正式分镜中必须写为 `015_小满绑架受冻版`。图内显示标题与文件名不一致时，以最终文件名主干为准。
3. 【本节出场的所有人物】和【本节的所有背景】每项只写一个最终资产名主干，不添加括号、别名、身份说明、状态描述或其他文字。
4. 后续逐镜引用同一资产时必须保持完全一致，不得删编号、缩写、同义替换或自行改名。

## 资产阶段先闭合

1. 角色与场景提取完成后，以最终 JSON、实际图片文件和映射表三方核对。
2. 同一人物的不同视觉状态分别生成带稳定后缀的资产；生成状态变体时引用既定身份基准图，锁定五官、年龄、体型、发型及核心辨识特征，只改变剧情需要的状态。
3. 原图更名时不覆盖用户原文件；保留“原文件名 → 最终文件名”对照表。
4. 在进入正式分镜前，所有实际需要的角色和场景资产必须存在并完成唯一命名。
5. 缺失资产返回第三步或第四步生成并登记；重名、近似名或映射不唯一时先核对确认。不得在正式分镜栏目中临时创建名称、写“新增，需新出图”或把不存在的资产伪装为已有资产。

## 每节填写流程

1. 识别本节实际入镜且按所选导演提示词应列入栏目的人物、生物和背景。
2. 核对剧情时间点、人物状态、场景状态及上一节连续性。
3. 在最终人物资产清单与最终场景资产清单中查找唯一精确匹配项。
4. 找到唯一项时，逐字复制最终文件名主干。
5. 找不到、存在多个候选或只能近似匹配时停止正式分镜，报告具体缺项或候选项并返回资产阶段处理。
6. 多个人物或多个背景逐项单独列出，不合并成模糊描述。

## 自检

- 是否每项均能反查到唯一实际图片文件。
- 是否完整保留三位编号和状态后缀，并去掉扩展名。
- 是否误加括号、别名、描述或临时标记。
- 是否把近似资产、错误状态版或同名资产当成精确匹配。
- 是否在发现缺失后先补齐资产，而非继续生成正式分镜。
