# 第六步：逐集生成15秒视频提示词

## 输入与规则来源

- 使用第五步已完成并核对的逐集剧本，沿用剧本的集号、正文顺序、对白、原有旁白和内心OS，不再直接从小说重新改编。
- 加载 [小六月最新提示词15s.txt](小六月最新提示词15s.txt) 的完整模板和导演规则，同时执行本文件对用户最新要求的覆盖。
- 回查用户确认的工作目录、作品类型和 `最终资产` 内的资产清单；执行 [资产名称映射规则](asset-name-mapping.md)。
- 提示词文件中的“只回复激活语、等待投喂”是原文的独立使用方式；输入已经齐全时直接执行本步骤，不重复索取已有正文或类型。

## 用户最新要求覆盖原文件的口径

紧凑模式是“台词、动作、反应同时推进”，不是单纯提高语速。原文件里的“快0.7—1秒”、4.9字/秒、13.0—14.3秒覆盖、为补时添加桥接台词等建议，不得覆盖下表，也不得成为删改剧本的理由。

| 项目 | 执行标准 |
| --- | --- |
| 每节时长 | 默认15秒，允许14—16秒 |
| 镜头数量 | 固定5镜，平均每镜约3秒；实际镜长按表演需要分配 |
| 有效对白字数 | 通常45—68个汉字，按实际读音计数，标点不计；数字、简称按实际读法展开 |
| 动态语速 | 约3.5—4.7字/秒，平均不超过4.7字/秒；关键词可以压慢，禁止全程快嘴 |
| 普通接话 | 间隔0.05—0.2秒，不等待对方把表情演完再接话 |
| 关键短停 | 证据、反转、关系变化等可保留0.05—0.35秒必要短停 |
| 有效声音覆盖 | 普通对白节目标13.8—14.5秒，按实际声音区间去重计算 |
| 开头和结尾 | 直接进入有效内容，无固定静场；结尾同镜余韵最多0.2秒 |
| 主提示词长度 | 沿用原文件：`((...))` 内不超过1400字符 |
| 文字和音乐 | 无字幕、无可读文字、无BGM |

字数只是容量参考，不能把68字直接判为“15秒必然说得完”。每句必须结合重音、停顿和动作核算；容量不足时在自然语义边界调整分节，不加快到上限以外，不删原文台词，不添加重复问答填时。锁定台词保持原字原序，源TXT中为配音转写同音字的建议不用于改写正文；只有用户另行要求注音或替字时才按其约定处理。

15秒沿用源文件的无可读文字要求；30秒允许特定原文道具字的授权不自动扩展到15秒。若某集剧情依赖读字证据而发生冲突，具体列出证据及需要可读的道具字，向用户确认处理；不能删掉证据、自动改成口播或默默改写剧情。

## 旁白、OS与画面

用户已确认：保留原有旁白／内心OS声音，同时配上对应动作和画面。此要求优先于源文件中删除心理解释、改成角色自言自语等一般建议。

- 大段旁白或OS要拆解为对应的可见事件、操作过程、人物互动、动作结果和即时反应；声音可跨镜连续，不能让人物站在原地干巴巴地想完整段。
- 旁白保持旁白，内心OS保持内心声，不擅自改成张嘴说出的对白，也不删原有音轨以换取节奏或覆盖达标。
- OS期间本人闭嘴，以表情、视线、手部动作、移动和真实事件承载；不得让其他人物对没有听到的内心声作知情反应。
- 画面不得凭空新增事实、人物关系、结论或时间顺序，也不得为表现心理而无依据插入新剧情。

## 类型与资产

1. 仿真人竖屏最终视频为9:16，采用真实摄影和仿真人视觉；替换模板中不适用的3D国漫、游戏CG等视觉词。
2. 漫剧横屏最终视频为16:9，采用3D漫剧视觉。原TXT标题中的“竖屏”不改变已经确认的类型。两种类型的角色图和场景图仍全部为16:9。
3. 【出场人物】和【出场场景】逐项复制资产清单中的实际文件名，完整保留序号、字词和扩展名，可在文件名后加括号说明身份、状态或用途；禁止使用别名、缩写、同义替换或仅写剧情描述。
4. 【出场人物】包含本节现场全部人物，包括沉默者；主提示词中的人物资产清单、人物表和实际画面人物一致。明确切到电话另一端时，登记其真实独立空间及对应人物、场景资产，不把两端放进同一房间。
5. 同一连续时空继承坐站姿态、位置、朝向、距离、双手、道具状态、未完成动作与惯性；未说话者持续倾听和即时反应。历史录音、电话声音、群消息不凭空生成实体分身。
6. 缺资产时列出所需人物／场景及状态，停止该节和后续生成，先补图、保存、登记再从中断处继续。

## 每集的执行顺序

1. 按集号读取一集剧本，核对上集尾部连续状态和项目声线表；同一人物的声音编号不因换集、换场或进入30秒版本而变化。
2. 以自然剧情节点划分15秒小节，保持整句台词、连续动作、因果和悬念。约120字符不再是任何切割依据。
3. 为每节核对现场人物、实际入镜场景及其精确资产文件名。
4. 逐句安排声音起止时间，再配置固定5镜；短句可在同镜接话，长句可跨镜以O.S.覆盖反应，不能机械“一句一镜”。
5. 将能同步的动作、台词、反应同时推进。吞咽、确认结果等必须先完成的动作保留真实时间；人物先接收信息再反应，先说完再挂电话。
6. 填写原TXT完整模板，原字段不能为缩短输出而省略；节奏、资产和画面内容按本文件覆盖。最后一镜必须看见最后实际发声的人；末句为其内心OS时，本人闭嘴。
7. 逐节完成下面的声音和画面检查，记录结尾状态和剧本消费结束位置，直至本集完整覆盖。
8. 按 [逐集交付规则](08-episode-delivery.md) 把本集全部15秒提示词保存为一个UTF-8 TXT至工作目录下的 `15s`，再处理下一集。

原文中无实体旁白、历史录音等若与“末镜看见最后发声者”发生实际冲突，先在不改动原文声音顺序的前提下调整自然分节；仍无法兼容时说明具体冲突并询问处理，不自行豁免尾镜规则，不凭空添加旁白人物或伪造已有资产。

## 声音覆盖与画面核对

1. **逐句排时。** 记录发声人、台词、实际读音字数和语音起止时间，用“读音字数÷该句实际发声秒数”检查说得完且不超过上限；停顿不能冒充发声时间。
2. **逐镜核对。** 固定5镜分别写清由哪句对白、旁白、OS、O.S.或必要动作声覆盖；同一跨镜语句不能重复计时。
3. **算区间并集。** 有效覆盖＝净人声时长＋人声之外独占的必要有效拟音时长。将所有有效声音的起止区间合并后求总长；人声与拟音重叠只算一次。
4. **排除虚假覆盖。** 风声、车流、房间底噪等持续环境声不计；静默读屏、思考、停顿、走路画面本身也不计。必要拟音只算真实可听到的瞬间，不把整个动作镜头时长当拟音。
5. **对照画面因果。** 检查先收到消息再反应、先说完再挂电话、物件先操作后出现结果，避免时间数字合格而事件顺序错误。
6. **如实标注例外。** 原文必须保留的静默阅读、明确沉默或动作导致低于13.8秒时，写明原因、具体区间和真实预算，不写“已达标”，不用新增台词、环境底噪或删掉原声补齐数字。

检查结果属于提示词逐句排时预算，不是生成后音频实测。用户贴出的第13—15集节数和覆盖区间只是历史示例，不复制为本项目的统计；成片仍须听看复核，不能保证模型严格执行秒点。
