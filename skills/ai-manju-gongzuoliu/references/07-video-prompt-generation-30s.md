# 第七步：逐集生成30秒视频提示词

## 输入与优先级

在全部15秒版本完成后，重新按集号读取第五步的同一套逐集剧本，加载 [小六月最新提示词30s.txt](小六月最新提示词30s.txt)，独立设计30秒分节和镜头。不能把两条15秒提示词简单拼接，也不能把15秒改编过程中添加的内容当成原剧本。

执行 [资产名称映射规则](asset-name-mapping.md) 及本文件的最新要求。原TXT中的6—8镜、4.9字/秒、27.0—29.0秒覆盖、为补时加桥接台词等口径，由下表覆盖；不因文件中的激活语重复等待已有输入。

## 30秒高密度紧凑节奏

| 项目 | 执行标准 |
| --- | --- |
| 每节时长 | 默认30秒，允许29—31秒 |
| 镜头数量 | 固定8镜，镜长按台词和动作分配，不机械等分 |
| 有效台词字数 | 通常90—136字，按句子难度调整；按实际读音展开数字、简称，标点不计 |
| 动态语速 | 约3.5—4.7字/秒，平均不超过4.7字/秒；关键词可压慢，禁止恒速快嘴 |
| 普通接话 | 间隔0.05—0.2秒 |
| 关键短停 | 证据、反转、关系变化等允许0.05—0.35秒 |
| 有效声音覆盖 | 普通对白节目标27.6—29秒 |
| 输出完整性 | 沿用小六月完整49字段、主提示词及固定8镜时间轴 |
| 长度限制 | 每条完整提示词≤10000字符，主提示词≤3000字符 |
| 文字与音乐 | 无字幕、无BGM；仅已确认的原文剧情道具字可读，文字不自动转成口播 |

原文台词逐字、按顺序保留，关键过程、动作和因果不为提速删减。保留原有旁白／内心OS声音，同时配上对应动作和画面；大段内容必须匹配动态事件、动作结果和人物反应，不能站桩独白。OS本人闭嘴，不改成张嘴对白，不让其他人听见或提前反应。此要求覆盖原文件中删除心理台词或为提速改写的建议。锁定台词保持原字原序，源TXT中为配音转写同音字的建议不用于改写正文；只有用户另行要求注音或替字时才按其约定处理。

短句同镜接话，长句跨镜不断声；反应镜尽量由上一句O.S.覆盖，动作和对白同步推进。咽下食物后再开口、先收到消息再反应、先说完才挂电话等物理和因果顺序必须留真实时间。不得用空镜、慢镜、重复解释、重复问答或无意义动作填满30秒。

## 资产、类型与连续性

- 【出场人物】和【出场场景】逐项复制资产清单的实际文件名，含完整序号和扩展名，可追加括号说明，但不缩写、改名、用别名或只写描述。主提示词资产清单与两模块及实际画面一致；缺资产停止该节和后续生成，补齐、保存、登记后再继续。
- 现场人物全部保留，包括沉默者；同一连续时空继承左右位置、坐站状态、朝向、距离、手脚、道具、未完成动作和惯性，未说话者持续倾听和即时反应。
- 电话双方保持独立物理空间；切电话另一端时使用其真实对应资产，不生成同处一室或实体分身。声音编号使用项目统一声线表，跨节、跨集及两种时长保持同一角色编号。
- 最后一镜给最后实际发声的人；末句为内心OS时本人闭嘴。开头直接进入有效内容，取消固定静场；结尾同镜余韵最多0.2秒，不额外加尾镜。
- 最终视频沿用已确认类型：仿真人竖屏9:16并替换不适用的3D视觉词；漫剧横屏16:9并使用3D漫剧视觉。所有角色和场景资产仍为16:9。
- 模板中的 `no text`、负面词“可读文字”按本次限定解释：禁止字幕、无依据新增文字；已确认的原文剧情道具字允许按原文呈现，不自行加口播读字。

无实体旁白、历史录音等若与末镜要求实际冲突，先在不改动原声音顺序的前提下调整自然分节；仍无法兼容时说明具体冲突并询问处理，不自行豁免尾镜规则，不凭空创造旁白实体或资产。

## 每集的执行顺序

1. 读取本集剧本、上集尾部状态、项目声线表和锁定资产清单。
2. 按自然剧情节点独立划分30秒小节，可连续完成同一事件链内的自然步骤，不能跨无关事件或跳过关键认知、执行、反应与结果。
3. 核对本节所有现场人物及实际入镜空间，复制精确资产文件名。
4. 逐句安排声音起止时间和动作前置关系，再设计固定8镜的不同镜长；长句跨镜保持连续，短句可同镜接话。
5. 完整填入49字段、主提示词和8镜时间轴；覆盖模板中的旧参数，核对原对白、旁白和OS的文字、顺序、归属及口型。
6. 执行下面的有效声音核算、画面因果与连续性检查，并核对两项字符上限；未解决的问题不能标成通过。
7. 记录每节消费到剧本的准确结束位置，整集无遗漏、重复、倒序和未经授权的新剧情后，按 [逐集交付规则](08-episode-delivery.md) 保存到工作目录下的 `30s`，每集一个UTF-8 TXT。

## 有效声音覆盖的核算

**有效声音覆盖＝净人声时长＋人声之外独占的必要有效拟音时长。**

1. 对每句记录实际读音字数、语音起止时间，用“字数÷实际发声秒数”检验合理语速；标点、停顿和静默读屏不当作人声。
2. 人声包括本集剧本实际对白、连续O.S.、原有旁白及内心OS；必要拟音只计真正推动剧情、实际可听到的动作声瞬间。
3. 将有效人声和必要拟音区间合并为并集，重叠只计一次。与人声重叠的拟音不能再累加，跨镜同一句也不重复计算。
4. 持续环境底噪、风声、房间声底不计；静默阅读、思考、停顿、走路画面本身不计。不能把整镜时长直接写成对白时长。
5. 逐镜说明01—08的声音来源及实际区间，再核对先收到消息再反应、先说完才挂电话等画面因果。
6. 净人声27秒＋独占必要拟音0.8秒＝27.8秒；净人声24秒＋6秒静默读消息，覆盖仍是24秒。
7. 低于27.6秒就是未达到普通对白节常规目标。原文必须保留的静默阅读、明确沉默或动作可作为例外，但必须注明原因、区间和真实覆盖数，不伪称达标，不删原声、不新增废话或拿底噪补数。

声音核算是提示词阶段的逐句预算，不是生成后音频实测。成片仍须听看复核；不能保证模型严格执行秒点。
