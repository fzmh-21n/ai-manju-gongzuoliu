# 第一步之后、第二步之前：确认项目工作目录与作品类型

## 确认节点

角色提取完成后、场景提取开始前，确认以下两项：

> 本次项目的工作目录是哪个文件夹？请提供完整路径。
>
> 本次制作“仿真人竖屏”还是“漫剧横屏”？

用户已提供的信息直接沿用，只问缺失项。必须由用户提供工作目录并明确选择类型；不得擅用桌面、工作区、临时目录或旧项目路径。两项不齐不进入第二步。不再询问角色图、场景图分别保存到哪里。

## 工作目录与自动创建的子文件夹

- 核实工作目录路径明确、确实指向文件夹且可写；用户指定的新项目目录不存在时可按指定路径创建，不改存别处。路径歧义或不可写时说明问题并询问。
- 第三步正式出图前，自动创建或复用 `工作目录/最终资产`。第三步全部角色图、第四步全部场景图均存入此处，统一维护 `资产清单.json`。
- 第五步转换剧本时创建或复用 `工作目录/剧本`，分集剧本每集一个UTF-8 TXT。
- 第六步生成15秒版本时创建或复用 `工作目录/15s`，每集全部15秒节保存为该集一个TXT。
- 第七步生成30秒版本时创建或复用 `工作目录/30s`，每集全部30秒节保存为该集一个TXT。
- 这些子文件夹名称已由用户指定，不为创建它们重复索要批准。用户明确更改工作目录时，更新所有派生路径，不能混入其他项目文件。
- 已有文件不静默覆盖；复用已验证的现有资产，或新增清楚的版本标识并更新清单。

## 类型与比例锁定

1. 全部角色图与四视角场景图统一16:9。
2. 仿真人竖屏：资产使用仿真人风格，15秒和30秒最终视频均为9:16。
3. 漫剧横屏：资产使用3D漫剧风格，15秒和30秒最终视频均为16:9。
4. 后续不重复询问、不默认切换，只有用户明确改选时更新。
5. 两套时长分别读取 `小六月最新提示词15s.txt` 和 `小六月最新提示词30s.txt`；文件来源标题中的“竖屏”不能覆盖用户已选横屏类型。

## 图片顺序与登记

1. 角色图依第一步JSON顺序，场景图依第二步JSON顺序生成；各状态沿用列表顺序。
2. 每生成一张立即保存到“最终资产”，记录类型、资产名、人物/地点、状态、顺序、实际文件名与完整路径。
3. 命名保持唯一、可追踪并含三位序号，例如 `角色图_001_王姨正常.png`、`角色图_002_王姨换装版.png`、`场景图_001_整洁的王姨客厅四视角.png`。
4. 视频提示词按 [资产映射规则](asset-name-mapping.md) 从清单复制实际文件名，包含序号、状态和扩展名；不要只写角色简称或场景描述。
