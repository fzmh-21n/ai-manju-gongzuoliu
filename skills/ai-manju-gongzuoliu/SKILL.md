# AI漫剧工作流

按角色提取 → 确认工作目录与类型 → 场景提取 → 角色图 → 场景图 → 分集剧本 → 15秒视频提示词 → 30秒视频提示词执行。用户明确要求的暂停节点或本次范围优先；未要求暂停时依次完成。

## 共同约束

- 用户提供的是项目工作目录，不再单独索要图片保存目录。全部图片保存到工作目录的 `最终资产`；剧本保存到 `剧本`；两套视频提示词分别保存到 `15s` 和 `30s`。按步骤自动创建这些子文件夹，已有则复用，不静默覆盖文件。
- 全部角色图、四视角场景图均为16:9。最终视频按已确认类型使用仿真人竖屏9:16或3D漫剧横屏16:9，两套时长沿用同一类型。
- 使用本包内用户提供的三份新提示词：`references/小说转剧本提示词.txt`、`references/小六月最新提示词15s.txt`、`references/小六月最新提示词30s.txt`。工作流中的用户覆盖规则优先于这些来源文本中的通用建议；不再调用旧导演提示词或每20节一文件规则。
- 大段旁白和内心OS保留原有声音，同时配上原文支持的动作、事件、反应与可见后果；不能让人物僵站着只靠声音解释。内心OS发声时本人闭嘴，不能擅自改为开口对白。
- 两套视频都必须在【出场人物】【出场场景】按资产清单逐项使用精确实际文件名（包括序号、状态及扩展名），不得缩写、替换或虚构。读取 [资产映射规则](references/asset-name-mapping.md)；缺资产先停止受影响的提示词，补图、保存、登记后再继续。
- 15秒与30秒分别从同一套分集剧本独立分节、排时和创作，不拼接15秒条目冒充30秒版本，不改写两套之间的对白、事件顺序或人物归属。

## 第一步：提取角色及明显外形变化版本

1. 读取 [角色提取规则](references/01-character-extraction.md) 和 [角色提取模板](references/prompt-character-extraction.txt)。
2. 通读完整正文，提取全部人物，包括“我”、无名人物及系统等非人类辅助存在；合并同一人物的代称。
3. 只有人物外形确实发生明显变化时才新增状态图，例如换了一套衣服、明显变装、年龄阶段变化、严重战损或落水后整体湿透沾泥。情绪、姿态、动作、站位、剧情身份或称呼变化而外形不变，不拆图；轻微汗水、小污点等也不自动拆图。
4. 同一人物各状态保留稳定身份特征，只改变原文支持的明显外形差异；不得为多出版本虚构换装或伤势。
5. 输出合法JSON数组，每项只有 `name`、`aliases`、`description`。

## 第一步之后、第二步之前：确认工作目录与作品类型

读取 [工作目录与类型规则](references/01b-image-output-folder.md)，确认：

> 本次项目的工作目录是哪个文件夹？请提供完整路径。
>
> 本次制作“仿真人竖屏”还是“漫剧横屏”？

已提供的信息直接沿用，只询问缺失项。必须获得用户提供的工作目录和明确类型才能进入第二步；不自行套用其他项目路径。检查路径和可写性。这里只确认工作目录，不要求用户另选角色图、场景图的保存路径。

## 第二步：提取场景及明显环境变化版本

1. 读取 [场景提取规则](references/02-scene-extraction.md) 和 [场景提取模板](references/prompt-scene-extraction.txt)。
2. 全量提取具体物理场景，合并同一空间的代称，忽略无具体画面的抽象地点。
3. 同一地点有显著环境变化时拆成独立状态，保留空间骨架及标志性元素；普通镜头角度变化不拆场景。
4. 全部描述采用无人、无动物的空镜模式。
5. 输出合法JSON数组，每项只有 `name`、`aliases`、`description`。

## 第三步：创建最终资产文件夹并生成16:9角色图

1. 读取 [角色图生成规则](references/03-character-image-generation.md)，回查已确认类型。
2. 正式出图前，在用户工作目录中创建 `最终资产` 文件夹；存在时复用。
3. 使用对应类型风格词与完整角色描述，为每个明显外形版本生成一张16:9角色设计板。
4. 按角色JSON顺序生成，每张立即保存到 `最终资产`；例如 `角色图_001_王姨正常.png`。
5. 在该文件夹的 `资产清单.json` 中登记资产名称、类型、人物、外形状态、实际文件名、完整路径和生成顺序；供后续精确复制文件名。

## 第四步：生成16:9四视角场景图

1. 读取 [场景图生成规则](references/04-scene-image-generation.md)，沿用同一类型及第三步创建的 `最终资产` 文件夹。
2. 每张提示词最前面原样加入：`请将图生成四个分格，每个分格是场景的不同视图和角度`。
3. 使用对应风格词及场景描述；每个场景状态生成一张16:9四分格图，四格均无人、无动物。
4. 同地点各状态保持结构和标志物一致。按场景JSON顺序立即保存，文件名如 `场景图_001_整洁的王姨客厅四视角.png`，同时更新 `资产清单.json`。
5. 检查图片实际文件及尺寸；提示词里的“4K/8K”不等于实际输出分辨率。

## 第五步：正文转换为分集剧本并保存

1. 读取 [剧本转换规则](references/05-screenplay-conversion.md) 和 `references/小说转剧本提示词.txt`。
2. 按原始小说/已改文案判断模式A/B，依据正文自然事件划分集数，保留原文对白、顺序、人物、因果与伏笔，维护剧本圣经及归属存疑记录。
3. 大段旁白/内心OS必须保留原有声音，并逐段配上有实际推进的画面；禁止用人物僵站、无意义空镜、读屏或自言自语替代事件。保持信息先到达、人物再反应的因果。
4. 在工作目录创建 `剧本` 文件夹，每集一个UTF-8 TXT，例如 `第01集_本集标题.txt`。圣经及核对台账与分集剧本清楚区分，不混进视频输入正文。
5. 检查正文覆盖、台词与声音保留、画面对应、人物归属及集间承接，再进入视频提示词。

## 第六步：逐集生成并保存15秒视频提示词

1. 读取 [15秒生成规则](references/06-video-prompt-generation-15s.md)、[分节与动作对白规则](references/06-section-sizing-and-action-dialogue.md) 和 `references/小六月最新提示词15s.txt`。
2. 逐集输入第五步保存的剧本，使用同一资产清单及已锁定类型；完整保留新提示词模板并应用本工作流覆盖规则。
3. 每节默认15秒，允许14—16秒，固定5镜；通常45—68个有效对白汉字，按实际读音计数，标点不计；动态语速3.5—4.7字/秒，平均不超过4.7字/秒。
4. 普通接话间隔0.05—0.2秒，反应镜由上一句O.S.覆盖，台词、动作、反应同时推进；开头无固定静场，结尾余韵最多0.2秒。最后一镜看见最后实际发声者，内心OS本人闭嘴。
5. 逐句排时、逐镜核对，按有效声音区间并集检查13.8—14.5秒覆盖；只计人声和不与人声重叠的真实必要拟音，不以环境底噪或整镜时长凑数。原文必要沉默/动作例外要写原因和真实覆盖，不能假报达标。
6. 【出场人物】【出场场景】复制资产清单的精确实际文件名；保留现场沉默者及跨节姿态、位置、距离、道具和声音编号，检查真实动作因果。
7. 在工作目录创建 `15s` 文件夹。按 [逐集保存规则](references/08-episode-delivery.md)，每集所有15秒节合成该集一个UTF-8 TXT；不按20节拆文件。

## 第七步：从同一剧本逐集生成并保存30秒视频提示词

1. 完成15秒版本后，读取 [30秒生成规则](references/07-video-prompt-generation-30s.md)、[分节与动作对白规则](references/06-section-sizing-and-action-dialogue.md) 和 `references/小六月最新提示词30s.txt`。
2. 再次逐集输入同一套剧本，按30秒容量重新分节及调度，不能简单合并两个15秒条目。
3. 每节默认30秒，允许29—31秒，固定8镜，按台词及动作分配镜长；通常90—136字，动态语速3.5—4.7字/秒，平均不超过4.7字/秒；普通接话0.05—0.2秒，关键停顿0.05—0.35秒。
4. 普通对白节有效声音目标27.6—29秒；逐句、逐镜核算净人声与独占必要拟音的区间并集。静默读屏、思考、持续底噪、重复累加的重叠拟音均不计；原文必要静默例外标清原因及真实覆盖，不伪称达标。
5. 保留原文台词逐字及顺序，大段旁白/OS保留声音并配对应动态画面；短句可同镜接话，长句跨镜不断声，动作与对白同步，必须先完成的动作留足真实时间。
6. 【出场人物】【出场场景】继续精确引用资产实际文件名，保留沉默者和全部连续状态，电话双方空间独立，尾镜给最后实际发声者；OS本人闭嘴。
7. 完整沿用新提示词49字段；每条不超过10000字符，主提示词不超过3000字符。无字幕、无BGM；仅已确认的原文剧情道具字可读，文字不自动转为口播。
8. 在工作目录创建 `30s` 文件夹；每集所有30秒节单独保存为该集一个UTF-8 TXT。这里保存的是30秒版本。

## 最终核对与交付

- 对照 [逐集保存规则](references/08-episode-delivery.md) 核实 `最终资产`、`剧本`、`15s`、`30s` 的文件和清单；两套视频文件与剧本集数逐一对应，同名不静默覆盖。
- 15秒和30秒各自完整覆盖每集剧本，无遗漏、重复、倒序、未经授权的对白改动或续写；分别记录消费位置及连续编号。
- 检查资产名逐字符匹配、现场人物完整、镜头数、声音排时、口型、动作因果、电话空间与集间连续性；未通过的条目返工。
- 声音覆盖是提示词逐句排时预算，不是生成后音频实测；成片仍需听看复核。用户粘贴的某批集数/节数/覆盖统计是示例，不得当作本次实测或固定集数。
- 报告实际完成集数、两套各自节数、文件数量及准确保存位置；如用户要求阶段暂停，只交付已授权阶段，不越过节点。
